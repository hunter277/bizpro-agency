# BizPro Agency - Multipurpose WordPress Theme

BizPro Agency is an enterprise-grade, multipurpose WordPress theme designed for agencies, consulting firms, IT solutions providers, visa & immigration consultants, and travel agencies.

## Key Features
- **6 Niche Homepages:** Main Agency, IT Solutions, Business Consulting, Visa & Immigration, Travel & Tour, Corporate Enterprise.
- **One-Click Demo Import (OCDI):** 6 starter demos included.
- **Mobile First & Bulletproof:** Off-canvas drawer menu, fluid typography, zero overflow.
- **Zero jQuery:** Lightweight vanilla JavaScript for blazing fast performance.
- **AdSense & SEO Optimized:** Auto-ads, in-content ads, JSON-LD Schema markup.
- **Dark Mode Support:** Automatic system detection + manual switcher.

## Installation
1. Download `bizpro-agency.zip`.
2. In WordPress Admin, navigate to **Appearance > Themes > Add New > Upload Theme**.
3. Select `bizpro-agency.zip` and click **Install Now**, then **Activate**.
4. (Optional) Install companion plugin `bizpro-agency-companion.zip` for full demo import capabilities.
